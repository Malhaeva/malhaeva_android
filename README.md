# 서비스 소개

# 주요 기능

## 1. AI 음성 면접 분석

1)질문 선택 후 음성으로 답변 녹음
AI가 답변 내용, 말투, 속도, 추임새(음, 어) 분석
피드백: "답변 시간 3분 초과", "어 10회 사용", "핵심 키워드 누락" 등

## 2. 데일리 미션 시스템

알림 → 미션 → 랭킹(최고의 답변)

매일 오전 9시 "오늘의 면접 질문 3개" 푸시 알림
자정까지 답변 완료 시 스트릭 유지
연속 달성 일수 게이미피케이션 (7일, 30일 배지)


## 3. 취준 커뮤니티

면접 후기 공유 게시판
질문별 토론 (이 질문 어떻게 답했어요?)
익명 응원 메시지

회원 정보 조회, 업데이트, 홈 화면 조회

### 현재 develop 브랜치 속 코드는 부분적으로 서버 연동 코드가 작성돼 있으나, baseUrl를 임의로 작성해둔 상태라 서버와 연동이 되지 않은 상태입니다.
### 앱의 흐름을 보시려면 no-api 브랜치 속 코드를 통해 확인해보시면 좋을 거 같습니다
